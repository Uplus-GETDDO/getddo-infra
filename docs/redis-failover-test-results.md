# 운영 Redis 장애 전환 시험 결과

실제 시험 결과는 실행 후 기록한다. 아래 항목은 검증 계약이며 성공 실측값이 아니다.
[구성과 운영 절차](redis-ha.md)를 따른다.

| 케이스 | 기대 동작 | 실제 결과 |
| --- | --- | --- |
| 복제본 추가·AZ 분리 | 서로 다른 AZ의 primary/replica, HA 활성, pending 없음 | 미실행 |
| A/C 공유 제한·TTL 해제 | 같은 카운터, 합산 한도 초과 429, 만료 뒤 업무 거절 | 미실행 |
| 메인 장애 전환 | TestFailover 1회로 기존 replica 승격, endpoint 유지 | 미실행 |
| 앱 재연결 | A/C 컨테이너 유지·재시작 0·제한 기능 복구 | 미실행 |
| 응모 전용 연결·이력 워커 | 기존 평가와 잔존 저널 처리 재개 | 미실행 |
| 정리 | 임시 시험 권한 삭제·실효 철회·prod/bootstrap 전체 plan 0 | 미실행 |

비동기 복제로 최근 카운터·차단 상태·DB 미반영 저널이 유실될 수 있다.
표본 보존은 무유실 보장이 아니며, 오류 미관측은 항상 무중단이라는 뜻이 아니다.

# GD-303: 운영 대시보드 읽는 순서

[Google SRE의 Four Golden Signals](https://sre.google/sre-book/monitoring-distributed-systems/)인 트래픽·지연·오류·포화도를 기존 `GETDDO Prod — API and hosts` 상단에 배치했다. 백엔드·서버·수집 설정이나 비밀번호는 변경하지 않는다.

| 위에서 볼 순서 | 의미와 해석 |
| --- | --- |
| 트래픽: API 요청/초 | 선택한 A/C의 최근 5분 평균 요청률. ALB 상태 검사 `/v3/api-docs`, Swagger, Actuator는 제외한다. 사용자 수나 동시 접속자 수는 아니다. |
| 지연: 성공 요청 p95 | 성공(2xx/3xx) 요청의 95%가 이 시간 이내에 처리되었다는 뜻. 선택한 서버의 histogram을 합쳐 계산하며 서버별 p95의 평균이 아니다. 오류 요청 지연은 아래 별도 선으로 본다. |
| 오류: 5xx 비율 | 전체 API 요청 중 서버 오류 비율. 4xx나 HTTP 200으로 반환된 업무상 실패까지 포괄하는 업무 성공률은 아니다. |
| 포화도: 가장 바쁜 DB 풀 | A/C DB 연결 사용률의 최댓값. 이것 하나로 전체 시스템 용량을 판단하지 말고 CPU·메모리·디스크·Tomcat·pending도 함께 본다. |
| API 수집 상태 | A/C 각각 1이면 Prometheus 수집 성공, 0이면 수집 실패. 실제 업무 처리나 DB 정상 여부까지 보장하지 않는다. |

`server` 선택은 기존 A/C/monitoring 필터를 사용한다. API 지표는 A/C만 있고, 호스트 지표는 monitoring도 있다. monitoring만 선택했을 때 API 카드가 비는 것은 정상적인 범위 차이다.

## 포화도 그래프

- 메모리: `1 - MemAvailable / MemTotal`. 캐시 전체를 고갈로 오해하지 않도록 사용 가능한 메모리를 기준으로 한다.
- 디스크: 파일시스템별 `1 - avail / size`. 루트 및 모니터링 데이터 디스크를 보며 가상·Docker 파일시스템은 제외한다.
- DB 연결: `active / max`. pending이 계속 늘거나 최대 연결에 가까우면 대기·연결 획득 시간도 확인한다. raw 그래프에 active/pending/idle/max를 함께 표시한다.
- Tomcat: `busy / configured max`. 현재 생성된 스레드 수를 최대치로 오해하지 않는다. raw 그래프에 busy/current/max를 함께 표시한다.
- 사용률의 80%/90% 색상은 참고선이다. 확정 SLO·장애 판정·알림 조건이 아니며 부하 시험 결과에 맞게 조정한다. 서버 오류율에는 임의 SLO 기준선을 넣지 않았다.

## 빈 값과 0 구분

- 요청 카운터가 있고 요청도 발생했지만 5xx 시계열만 없으면 오류율 0%로 표시한다.
- 요청이 0이면 오류율의 분모가 없으므로 빈 값이다. 요청/수집 지표가 없을 때도 0%로 채우지 않는다.
- 성공 요청이 없으면 p95는 정의되지 않는다. `—` 또는 `No data`는 정상 0이 아니다. 먼저 API 수집 상태와 트래픽을 확인한다.
- DB·스레드 최대치가 없거나 0이면 비율을 표시하지 않는다. Infinity나 임의 0으로 채우지 않는다.
- 요약은 최근 5분, CPU는 최근 2분의 rate를 사용한다. 짧은 피크와 소량 트래픽은 원본 그래프·로그와 함께 확인한다.

상단의 CloudWatch 앱 로그 링크는 서울 리전의 기존 `/getddo/dev/api` 그룹으로 연결한다. AWS 로그인이 필요하며 로그 이벤트에서 `ERROR`/`Exception`을 검색한다. 로그를 Grafana에 공개로 복사하거나 새 로그 수집 경로를 만들지 않는다. 이름의 dev는 기존 운영 자원 이름이다.

이 대시보드는 앱/호스트 내부 지표를 보여준다. CloudFront/ALB에서 앱에 도달하기 전에 발생한 오류는 기존 CloudWatch 대시보드에서도 확인해야 한다. 외부 사용자 관점의 가용성 시험, SLO/에러 버짓, 알림·부하 시험을 구현한 것은 아니다.
